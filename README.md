# Описание заданий проекта C#

## Exercise 1. Вычисление площади выпуклого четырехугольника

Реализован математический модуль для вычисления геометрических фигур. Применяются простые типы данных (value types), работа с вещественными числами типа `double`, математические операции и формулы. Реализована обработка ошибок ввода через циклы и условные операторы. Используется формула Герона для вычисления площади треугольников.

**Используемый стек:**
- Простые типы данных (double)
- Математические операции
- Управляющие структуры (циклы, условия)
- Обработка исключений
- Парсинг строк

---

## Exercise 2. Решение системы линейных алгебраических уравнений методом Гаусса

Разработан модуль для решения систем линейных алгебраических уравнений методом Гаусса. Работа с многомерными массивами для хранения матриц, чтение данных из файлов через классы `File` и `StreamReader`. Реализован алгоритм прямого и обратного хода метода Гаусса. Обработка ошибок файлового ввода-вывода и валидация данных.

**Используемый стек:**
- Многомерные массивы (массивы массивов)
- Файловый ввод-вывод (System.IO: File, StreamReader)
- Целочисленные типы (int)
- Алгоритмы линейной алгебры
- Обработка исключений файловой системы

---

## Exercise 3. Работа с очередью: перестановка элементов колоды карт

Реализована логика работы с коллекцией данных через структуру данных очередь (Queue). Применяется алгоритм перестановки элементов массива с использованием FIFO принципа. Работа с целочисленными массивами, удаление элементов из коллекции, сортировка данных. Освоение базовых операций с очередями: Enqueue и Dequeue.

**Используемый стек:**
- Массивы (int[])
- Коллекция Queue<T>
- Алгоритмы сортировки
- Управляющие структуры (циклы while/for)
- Операции с коллекциями

---

## Exercise 4. Реверс односвязного списка с использованием стека

Создана реализация односвязного списка (singly linked list) через пользовательский класс. Применяется структура данных стек (Stack) для временного хранения узлов. Работа со ссылочными типами данных, манипуляции с указателями на узлы списка. Реализован алгоритм перестановки узлов без изменения значений, только через изменение связей между узлами.

**Используемый стек:**
- ООП (классы, ссылочные типы)
- Односвязный список
- Коллекция Stack<T>
- Указатели (ссылки на объекты)
- Рекурсивные алгоритмы

---

## Exercise 5. Подсчет частоты вхождения слова в тексте

Разработан модуль для обработки текстовых данных. Работа со строками (string), чтение и запись в файлы, работа с массивами строк. Реализован алгоритм поиска подстроки в тексте, подсчет вхождений. Применяется файловый ввод-вывод для чтения исходных данных и записи результатов. Обработка ошибок при работе с файлами и валидация входных данных.

**Используемый стек:**
- Строки (string)
- Массивы строк (string[])
- Файловый ввод-вывод (File, StreamReader, StreamWriter)
- Методы работы со строками (IndexOf, Contains)
- Обработка исключений

---

## Exercise 6. Поиск максимального пути в дереве

Реализована работа с древовидной структурой данных. Создание дерева через массив родительских элементов, обход дерева алгоритмами поиска в глубину или ширину. Работа со структурами (struct) для представления узлов дерева. Реализован алгоритм поиска максимального пути с условиями на значения узлов. Применение рекурсивных алгоритмов для обхода графовых структур.

**Используемый стек:**
- Структуры (struct)
- Деревья и графы
- Рекурсия
- Массивы
- Алгоритмы обхода графов (DFS/BFS)
- Работа с символами (char)

## Exercise 7. Работа с ассоциативными коллекциями (Dictionary)

Применение ассоциативных коллекций через класс Dictionary<TKey, TValue>. Работа со ссылочными типами данных, использование строк как ключей и вещественных чисел как значений. Реализованы операции добавления элементов в словарь, итерация по коллекции, вычисление среднего арифметического. Обработка валидации данных и форматирование вывода с заданной точностью.

**Используемый стек:**
- Dictionary<TKey, TValue>
- Ссылочные типы
- Строки (string)
- Вещественные числа (double)
- Итераторы (foreach)
- Форматирование чисел
- LINQ (опционально)

## Exercise 8. Управление коллекцией студентов с использованием List<T>

Создание пользовательского класса с полями и реализация объектно-ориентированного подхода. Разделение кода на несколько файлов, работа со ссылочными типами данных. Применение коллекции List<T> для хранения объектов пользовательского класса. Реализация поиска элементов в коллекции по условию. Обработка ввода данных и валидация.

**Используемый стек:**
- ООП (классы, поля класса, ссылочные типы)
- Коллекция List<T>
- Разделение кода на файлы
- Поиск в коллекциях

## Exercise 9. Реализация собственной обобщенной коллекции MyList<T>

Реализация собственного обобщенного класса (generic class) с использованием универсальных шаблонов (generics). Создание класса MyList<T>, имитирующего функциональность стандартной коллекции List<T>. Реализация методов Add, Count и Remove. Понимание работы с типами-параметрами, инкапсуляция данных через поля класса, управление размером коллекции.

**Используемый стек:**
- ООП (generics, обобщенные классы, типы-параметры <T>)
- Инкапсуляция
- Реализация коллекций
- Массивы с динамическим размером
